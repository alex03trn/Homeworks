
## Что делает контейнер

При запуске контейнера выполняется `sscript.R`, который:

1. Проверяет, установлена ли библиотека `dplyr`, и выводит её версию.  
2. Генерирует тестовые данные `df_raw`.  
3. Вычисляет агрегированные статистики (`detailed_stats`) по примеру из задания.  
4. Создаёт три типа **анти-джоинов**:
   - `anti_left`  
   - `anti_right`  
   - `anti_outer`  
5. Сохраняет все результаты в папку **`data/`**.

Папка `data` монтируется снаружи, поэтому:
- входные данные **не копируются в образ**;
- результаты остаются у вас на диске после завершения контейнера.

---

## Сборка Docker-образа

Выполните в корне проекта:

docker build -t r-joins .

docker run --rm -v "$(pwd)/data:/data" r-joins
